# 🌱 Primeiros Passos - Meu Laboratório de Estudos

Este repositório é o meu "caderno de códigos" inicial. Aqui registro o início da minha jornada em cada tecnologia, guardando os primeiros scripts, exercícios de lógica e projetos fundamentais que desenvolvo enquanto estou descobrindo uma nova linguagem.

> "A base de todo grande projeto começa com os primeiros códigos."

---

## 🚀 O que tem por aqui?

Este diretório está organizado pelas linguagens que marcaram o meu ponto de partida na programação:

* **☕ Java:** Meus primeiros contatos com Programação Orientada a Objetos e lógica estruturada.
* **🐍 Python:** Scripts de automação, sintaxe básica e lógica simplificada.
* **⚡ Javascript:** O início da minha jornada no dinamismo e interatividade para Web.
* **🌐 Web (HTML/CSS):** A construção das minhas primeiras páginas, estruturas e estilos.
